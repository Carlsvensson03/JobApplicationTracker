# JobApplicationTracker
Jobapplication tracker är ett program där man kan lägga till jobbansökningar och och ha reda på alla sin anökningar. 
Man kan få fram statiskt och sotera sina ansökningar, man kan ändra status eller ta bort dem. 
Det är ett program som med hjälp av en meny gör det smitigt för en användare att ha bra översikt över sina jobbansökningar.

För att köra progammet öppnar man projektet i sin terminal och kör dotnet run.
